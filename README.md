# Zirkel Timer

Intervall-Timer für Zirkeltraining. Läuft komplett im Browser, keine Installation nötig.

**App:** https://woutlwhite.github.io/IntervalTimer/

## Funktionen
- Runden, Belastung, Pause, Rundenpause und Vorbereitungszeit einstellbar
- Übungen benennen, hinzufügen, löschen, umsortieren
- Beeps bei 3-2-1 und bei jedem Phasenwechsel
- Workouts als Vorlagen speichern (im Browser des Geräts)
- Bildschirm bleibt während des Trainings an
- Zurück / Pause / Weiter während des Workouts

## Tipps
- **Zum Homescreen hinzufügen** (Safari: Teilen → „Zum Home-Bildschirm“), dann startet die App wie eine native App im Vollbild.
- Auf dem iPhone ist ohne Ton, wenn der Lautlos-Schalter aktiv ist.
- Rundenpause auf 0:00 = zwischen den Runden wird die normale Pause verwendet.
